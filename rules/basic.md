# 基础协作原则

本指南补充仓库和模块的 `AGENTS.md`；用户的明确指令和已提供的授权优先。按任务复杂度选择需要的流程，不为简单修改强制创建阶段文档。

- 先核查相关实现、调用方、文档和已有工具；结论应有可验证的证据。
- 根据变更范围评估兼容性、数据和安全风险，优先采用满足需求的最小修改。
- 只有缺失信息会实质影响结果、涉及关键取舍或用户明确要求批准时，才请求决定；用户已提供的授权无需重复确认。
- 独立推进已授权的工作；出现相关进展、失败或需要用户操作时及时说明。
- 针对变更行为和失败路径执行适当验证，报告结果及尚未验证的限制。
- 遇到失败时先检查原因和可用的替代路径；确需用户输入或外部状态变化才能继续时，说明阻碍及已尝试的操作。
